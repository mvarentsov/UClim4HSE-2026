# Домашние задание №7

## Микромасштабное моделирование с ENVI-met

В рамках задания необходимо:

- Выбрать по данным метеорологических наблюдений для вашего города день для моделирования, релевантный для сценариев, которые вы выберете далее (с жарой/сильным ветром/плохими условиями рассеяния примесей). 

- Подготовить конфигурацию ENVI-met для выбранного района города с помощью Spaces или плагина для QGIS. Учитывайте ограничения бесплатной версии модели (не более 50*50 ячеек сетки). Рекомендуется задавать шаг сетки не более 10 м. Необходимо задать реалистичную (без фанатизма) конфигурацию зданий, деревьев, типов подстилающей поверхности на основе данных OpenStreetMap и/или Overture Maps (можно использовать результаты [домашнего задания №4](https://github.com/mvarentsov/UClim4HSE-2026/blob/main/homeworks/HW4.md)). Уточнять данные о высоте зданий, для которых она неизвестна, можно путем правки атрибутивной таблицу QGIS или вручную в Spaces, на основе данных об этажности, Яндекс/Google панорам и т.д. , на основе данных об этажности. 

- Провести контрольный численной эксперимент с моделью для периода продолжительностью 3 часа начиная в пределах выбранного дня с метеорологическим форсингом по данным наблюдений или реанализа (с учетом ограничений бесплатной версии модели по его заданию).  

- Провести один или несколько (при желании) сценарных эксперимент для того же периода, с таким же форсингом, но с изменением свойств городской среды (например, добавление деревьев и других видов озеленения, добавлением новых зданий, изменение высоты/формы/материалов существующих - включайте полет фантазии).

- Подготовить описание экспериментов и результатов моделирования (в формате Word/PDF). Оно должно включать:
  - Особенности выбранного для моделирования дня
  - Визуализацию области моделирования, краткое пояснение, как задавались параметры застройки и поверхности
  - Описание дополнительного эксперимента (что менялось относительно контрольного)
  - Визуализацию приземной (на высоте 1.5-2 м) температуры и скости ветра (при необходимости - других релевантных для вашего эксперимента метеовеличин) для контрольного эксперимента, их интерпретацию
  - Визуализацию и интерпретацию результатов сценарного эксперимента и его сравнения с контрольным.
